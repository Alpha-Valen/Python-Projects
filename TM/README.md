# Alpha Nexus Task Manager
A command-line interface built in Python as a part of my programming learning journey and the Alpha Nexus project ecosystem. 
CLI for now. . . I have plans.

## Why I am building this? Funny you'd ask. . . 

This project started as a way to practice basic Python concepts.
It has since gotten slightly out of hand.

What started as a simple task manager has grown into a project where I can experiment with new concepts as I learn them and gradually improve the program over time.

## Current Features
- Add individual tasks
- Add muiltple tasks
- Assign task priorties
- Validate user input
- Edit existing tasks 
- Mark task as completed
- View active tasks
- View completed tasks
- Sort tasks by priority
- Save and load task between sessions
- Handle invalid input and edge cases
- Easter eggs (😏)
- A 'mildly' judgemental user interface

## What I'm Practicing

- Loops and conditionals
- Error handling
- File I/O and persistence
- Program organization
- GitHub and Git workflows

## Project Status

⚒️ Work in Progress

This project is intentionally evolving alongside my Python knowledge. 
New features, refactoring, and probably unnecessary amounts of personality will be added as I learn new concepts.
The point is to build with what I currently know, discover where the design becomes hard, learn better approaches and then improve it. 

Breaking things is permitted.
